# ベビま 名付けノート v2

## 追加済み
- 比較画面（最大4候補）
- 候補 / 保留 / 却下
- まこしゃ★ / なえちゃ★ を別管理
- 漢字の意味
- 名乗り読み
- 書き順メモ
- タグ
- コメント
- 自分の履歴だけ削除
- 提案者表示
- 読み・画数・文字数・★数などでソート
- iPhone PWA対応
- Supabase共有対応

## 書き順について
v2では手入力欄です。将来、漢字辞書や書き順データAPIに接続できるよう項目を分離しています。

## 共有
Supabaseを使う場合は `supabase_setup.sql` をSQL Editorで実行してください。
既にv1を使っている場合でも、同SQLを再実行すれば不足列が追加されます。

## 注意
簡易試作版のため、家族コードは本格的な認証ではありません。外部公開する場合はSupabase Auth推奨です。
